# TinyFX Basic Example

A minimal working example of the TinyFX framework.

This example demonstrates:
- A static page (`src/pages/index.html`)
- A dynamic component with signals (`src/components/Counter/`)
- A simple dynamic component (`src/components/Greeting/`)

## Getting Started

```bash
npm install
tinyfx build
```

Then open `dist/index.html` in a browser, or run:

```bash
tinyfx serve
```
